NailyBest PWA 3.7

این بسته برای GitHub Pages آماده شده است.

فایل‌ها:
- index.html  ← حتماً با حروف کوچک
- manifest.webmanifest
- sw.js
- icons/*

نکته:
1) همه این فایل‌ها را در همان پوشه‌ای که GitHub Pages از آن منتشر می‌کند قرار دهید.
2) دکمه «پیام یادآوری» حالا برنامه پیامک گوشی را با شماره مشتری و متن پیام باز می‌کند.
3) برای دیدن لوگوی جدید روی آیکون نصب‌شده، بعد از انتشار نسخه جدید، PWA قبلی را از صفحه اصلی حذف و دوباره از مرورگر نصب کنید.
